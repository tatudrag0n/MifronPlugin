# Mifron Plugin

Paper 26.1.2向けのMifronサーバー統合プラグインです。実装に基づく詳細仕様は [`docs/non-ffa-code-spec.md`](docs/non-ffa-code-spec.md) と [`docs/SPECIFICATION.md`](docs/SPECIFICATION.md) を参照してください。

新規参加からチュートリアル・メニュー・SHOP・インベントリ分離・MP永続化までのE2Eテストは `../mifron-bot` (Mineflayer) で自動化しています。直近の実機結果と未対応範囲は [`docs/E2E_TEST_REPORT.md`](docs/E2E_TEST_REPORT.md) を参照してください。

## ハイライト

- **SHOP・棚/樽ショップ** — カテゴリ別SHOP、全棚で在庫を共有する棚ショップ、樽を使った販売・買取ショップ、通常商人と秘宝商人を提供。購入・売却はMPで決済されます。
- **安全なプレイヤー間取引** — `/trade` で相手と向かい合い、専用UIでアイテムとMPを同時交換。提示を変えると確定がリセットされる詐欺防止設計で、途中退出でも提示は全額返却されます。メニューの「取引」から相手選択だけで申込完了。
- **扇状メニュー** — メニューアイテムを右クリックすると項目が目の前に扇状に展開。左クリックで選択でき、ステータスなどの詳細画面は従来どおり専用UIが開きます。
- **レリック** — 低確率で素材から変化する特殊アイテム。フックショット・ジェットパック・スケートブーツ・残響の結晶・ファイアーボール・朽ちた剣・金剛の砥石・サプライズ・チェーン・巨人の心臓・空に海写す蒼球・バニーホップ・反射の守護盾・磁力の石・剝蝕矮星・呼雷の銅杖・次元の眼・死不知のトーテム・凋零の頭骨・シングル・ベル・竜の吐息・暗視鏡・ときを刻む時計・反重力戦鎚・古代の斬鎧・獄炎の魔導書・無尽の魔導書・古匠の金床・ゲイ・ボルグ・エクスカリバー・レプリカ・六連装弩弓・狙撃弓・無限のバンドル・ノアの方舟。レリックは耐久値を持ち、使用で消耗します。
- **転生・称号・図鑑** — 全進捗達成後の転生、称号21種以上、レア収集の図鑑UI。
- **Discord連携・認証・投票** — MinoruブリッジAPIによるWeb側とのMP連携、提案・投票パネル。
- **全体チャットのみ** — ゲーム内は全体チャットを提供し、個人宛DM(`/tell`・`/msg`・`/mail`など)は電気通信事業の届出対象になるため廃止。該当コマンドは遮断し、案内はDiscordへ誘導します。
- **ログボ・復帰ボーナス・投票** — メニュー「ログボ」で連続ログイン・累計・次の節目を確認でき、節目達成は追加報酬と全体告知。14日以上ぶりの復帰ボーナス、メニュー「投票」から投票サイトへ。
- **初日導線と紹介制度** — 初参加は歓迎表示、チュートリアル卒業は全体告知+「目標」チェックリスト(5項目・各300MP)。`/mf refer` の6桁コードを新規プレイヤーが使うと、相手の卒業時に双方へ紹介報酬。
- **遊び方ガイド** — 卒業時・`/mf guide`・メニュー「ガイド」で「Mifron はじめの一歩」を配布。MP・SHOP・クエスト・取引・提案・投票・ログボ・紹介・保護を説明します。旧版の本は次回ログイン時に自動更新されます。
- **定期イベント** — config駆動の週次イベント(既定: 毎週土曜20:00「釣り大会」)を15分前・開始・終了に自動告知。イベント開催中だけ表示される限定クエスト(S30)。管理者は `/mf event list|start <id> [分]|stop` で手動開催できます。

## コマンド

- メイン: `/mifron`、短縮: `/mf`
- プレイヤー向け: `/mf balance`、`/mf pay <player> <amount>`、`/mf tutorial [restart|skip]`、`/mf guide`、`/mf relics`(レリック図鑑)、`/mf vote`、`/mf menu`、`/mf quest`、`/mf protect chunk`、`/mf refer [code]`、`/trade <player>|accept|deny|cancel|money <額>`(`build-world` が既定無効のため `/mf build` は省略)。`/mf relic` は管理者専用で、`/mf relic all [player]` は全レリックを付与します。
- 卒業時と `/mf guide` で、MP・SHOP・クエスト・取引・提案・投票・ログボ・紹介・保護をまとめた遊び方本「Mifron はじめの一歩」を配布します(メニューの「ガイド」からも取得可)。Buildワールドは既定で無効のため、ガイドでは案内していません。旧版のガイド本は次回ログイン時に自動で最新版へ更新されます。
- `/mv` はMifronでは登録せず、Multiverse-Core専用です。
- 管理系サブコマンドは原則 `mifron.admin` または個別権限が必要です。
- 廃止コマンド: `/mshop`、`/friend`、`/mf check`、`/mf debugopen`、`/mf marchant`、`/mf special`。`/mf build` / `/mf main` は機能有効時のみタブ補完に表示します。

## プレイヤー向け主要仕様

- 参加時に配布されるのは「メニュー」1個だけです(旧配布アイテム: ウォレット・ステータス・テレポーター・フレンド帳・クエスト帳・オンラインショップ扉・ストア案内は参加時に回収します)。
- メニューの「ウォレット」をクリックするとMP残高を確認できます。「メニュー」は旧ウォレットアイテム(emerald_bundle)と同等の棚ショップの決済アイテムです。アイテム収納には使えません。
- チャットは全体のみです。`/tell` `/msg` `/w` `/whisper` `/message` `/m` `/t` `/r` `/reply` `/mail` `/em` `/email` と `/team msg` は遮断されます(個人宛はDiscordをご利用ください)。
- 通常のエメラルドはMPへ変換されません。死亡すると所持MPの50%を失います。
- 棚ショップの商品は見本で、在庫は同じ素材について全棚で共有されます。棚の購入は「メニュー」を右手に持って右クリックで在庫とMPを消費し、棚の商品と同じ通常アイテムを持って右クリックすると1個売却します。「メニュー」を右手にした棚ショップの右クリックは、ファンメニューを開かずに購入になります。
- 空の樽の上に棚を置くと樽ショップになります。販売棚は樽内の在庫を1個ずつ購入でき、買取棚は持っているアイテムを樽へ売却できます(既定価格は1,000MP)。棚と樽は作成者のみ開けます。
- SurvivalではTNTと溶岩が無効です。ショップ化ブロックと承認済み建築は通常破壊できません。

## レリック

低確率で素材が変化して入手できる特殊アイテムです(売買不可・PDCの `relic_id` で判定)。入手経路は「アイテム入手・クラフト時の低確率変化」「`/give` やクリエイティブ取得時の同じ確率判定」「Elite討伐時のドロップ」「チュートリアル配布」など。管理者は `/mf relic <id> [player]` で確認・付与できます(旧IDは新IDへ自動移行)。

## 特殊クラフト

- **高度な作業台**: 通常の作業台で鉄ブロック4個を2×2に並べると作成できます。
- **鋼鉄かまど**: 高度な作業台で鉄ブロック8個を環状に並べ、中央に furnace を置くと作成できます。精錬速度2倍、燃料の持ち時間2倍です。
- 高度な作業台以外の特殊クラフトは、高度な作業台でのみ行えます。

## 安全取引(/trade)

- `/trade <player>` で申込、相手の `/trade accept` で共有UIを開きます。メニューの「取引」から相手選択UIでも申込できます。
- 提示枠(各16枠)+提示MPを設定し、双方が確定すると同時に交換されます。提示を変更すると双方の確定がリセットされます。
- 閉鎖・退出・タイムアウト時は提示を返却します。1回の提示MP上限は `trade.max-amount`(既定100万MP)です。

## 設定

`src/main/resources/config.yml` には現行コードが参照する設定だけを置きます。

- `trade`: 取引のMP上限。
- `build-world`: プレイヤー別Buildワールド、ワールド境界、初期足場。WorldEdit権限は滞在中だけ付与されます。既定は無効(`enabled: false`・共有Creativeワールドは廃止済み)で、有効化した場合のみ `/mf build enter|exit` が動きます。
- `world-rules`: 全ワールドのKeepInventory、PvP、固定昼、スポーン位置。
- `regen.excluded-chunks`: 自然再生成から除外するSurvivalチャンクの除外リスト。`/mf regen allow` で除外解除、`deny` で除外登録、`list` で除外一覧を確認し、`/mf regen [radius]` は Survival・ロード済み・保護外・除外外のチャンクだけを再生成します。月次の自動再生成(`regen.interval-days` / `monthly-enabled` / `monthly-max-chunks`)も参照します。
- `regen.nation-chunks` / `public-facility-chunks` / `staff-excluded-chunks`: 中央範囲以外の保護チャンク。
- `minoru-bridge`: ローカルAPIの有効化、待受、共有シークレット。`serverSecret` は旧設定からのフォールバックです。

再生成は破壊的操作のため、半径は最大8です。未ロードのチャンクは自動スキップします。実行前にバックアップを取得してください。

## 保護の実装範囲

Vanillaの `spawn-protection` はカスタムショップ操作より先にイベントを止める可能性があるため、推奨値は `0` です。

```properties
spawn-protection=0
```

Mifronの保護チャンクでは、扉・ボタン・コンテナ・額縁・防具立て・看板・ホッパー移送と、爆発・ピストン・液体・延焼を制限します。通常のブロック破壊・設置は現行の中央チャンク保護では止めていません。ショップ化ブロックとSurvivalへ設置した承認済み建築は別処理で破壊・設置から保護されます。

## 提案・審査

- クエスト提案は `/mf quest propose` でゲーム内作成できます(種類→名前→条件→必要数→報酬→依存→称号)。採用は運営審査です。
- `/mf vote` で提案中クエストの一覧を開き、賛成投票・取り消しができます。メニューの「投票」は VotingPlugin の外部投票サイトで、提案投票とは別です。
- 管理者は `/mf proposal list|review|approve|forceapprove|reject|reload` で審査します。外部から `proposals.yml` へ入った提案も対象です。
- 建築の提案提出(`/mf structure submit`)はBuildワールドを有効化した場合のみで、既定では使用できません。
- `/mf regen` は管理者権限が必要です。`allow` は除外解除、`deny` は除外登録、`list` は除外一覧、半径指定で強制再生成します。再生成対象は Survival のロード済み・保護外・除外外チャンクだけです。

## 保存データ

- `data.yml`: UUID、名前、MP、ステータス、フレンド、ショップ、各種進捗。
- `quests.yml`: クエスト定義。デイリー・ウィークリーは各期間5件、マンスリーは固定表示、スペシャルは条件解放です。
- `structures.yml`、`text-displays.yml`: 管理コンテンツと設置記録。
- `proposals.yml`: 外部から投入された提案と審査結果。
- `inventory-groups/*.dat`: Survival系と通常系のインベントリ、装備、オフハンド、選択スロット、XP、満腹度、隠し満腹度。
- `minoru-bridge.yml`: API取引の重複防止状態。

これらはサーバー固有データのため公開リポジトリへ追加しないでください。
