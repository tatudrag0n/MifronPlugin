## あえて入れていないもの（仕様準拠のため）

- **ギアシステム**：SPEC §8で廃止済みのため訴求しない。
- **個人宛DM（/tell等）**：全体チャットのみの方針（ChatPolicyFeatureで遮断）のため、コミュニケーション訴求は入れていない。
- **Buildワールド／建築提出**：`build-world.enabled` 既定 `false` のためPRでは扱わない（有効化時のみ使える機能）。
- **FFA等の未記載要素**：本動画は `docs/non-ffa-code-spec.md` と SPECIFICATION の記載範囲に限定した。

## 制作メモ

- **映像:** Pillowによるプログラムレンダリング（Ken Burns、シーンごとにフェード＋スライドインするテロップカード、字幕焼き込み、進行バー）。背景4点はAI生成イメージ（`assets/`）。実機画面と誤認させないため、本編でも「イメージ」前提のモーショングラフィックスとして構成している。
- **音声:** 日本語ナレーション（`audio/narration-01〜08.mp3`、シーン長は各ナレーション実尺＋前後パディングで自動決定）。BGMはスクリプト生成のオリジナル・チップチューン風ループ（C–G–Am–F、外部音源不使用）。
- **再生成:** `python3 -m venv pr-video/.venv && pr-video/.venv/bin/pip install pillow numpy imageio imageio-ffmpeg japanize-matplotlib` の後、`pr-video/.venv/bin/python pr-video/render.py`。音声だけ直す場合は `pr-video/fix_audio.py`（映像ストリームは無劣化コピー）。
- **フォント:** IPAexゴシック（`fonts/ipaexg.ttf`、IPAフォントライセンス）。
- **法的注意:** MifronはMojang／Microsoftの公式・公認サービスではない（README「法的注意」に準拠）。公開時はこの一文の併記を推奨する。
