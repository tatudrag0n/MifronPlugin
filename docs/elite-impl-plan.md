# エリート機能 実装計画（現行ブランチへ新規実装）

## 前提

- 現行の正ブランチ: サーバー `main`（`b04f90d`、聖剣仕様 `b4af24f` を含む）
- ローカル `repos/MifronPlugin` は別系統。エリート関連の実装がこちらにだけ存在する
  （腐死王 13箇所 / 異空の支配者 6 / 極炎の化身 6 / ラグナロク 19）
- 分岐が大きいため **マージではなく、ローカル実装を設計図として現行ブランチに書き起こす**
- 連射式弩弓・狙撃弓・アルテミスは現行ブランチに**既にある**ので対象外

## 現行ブランチの状態（`EliteMobFeature.java`）

あるもの:
- `spawnElite(Player, EntityType)` … コマンド等からの**手動**スポーン
- `tickElite(Mob)` … 毎tick処理
- `bossBarTitle(Mob, EliteState)` / `bossBarColor(EntityType)` … ボスバー
- `EliteState` による状態管理

ないもの（＝今回の実装対象）:
- 自然沸き
- 固有の名前（腐死王・異空の支配者・極炎の化身 等）
- 体力強化
- 腐死王の復活（アンデット特攻以外で倒された場合）
- 第二形態の対象制限
- 異空の支配者 / 極炎の化身の固有行動
- ラグナロクイベント

## 実装順（依存関係順）

1. **基盤: 自然沸き + 固有の名前 + 体力強化**
   - `CreatureSpawnEvent` を監視し、条件（夜・バイオーム・確率）で elite 化
   - `EntityType -> 名前` の対応表を新設
   - 最大体力を倍率で強化（`setMaxHealth` / `setHealth`）
   - ※ここが動かないと他が全部乗らない

2. **腐死王（ゾンビ系）**
   - ゾンビ/ハスク/ドラウンド → 腐死王 / 砂漠の腐死王 / 海淵の腐死王
   - 死亡時、 killer の武器に Smite（アンデット特攻）が無ければ復活

3. **第二形態の対象制限**
   - エルダーガーディアン / ピグリンブルート / ウィザー / エンダードラゴン / ウォーデン のみ許可

4. **異空の支配者（エンダーマン）**
   - 上空へテレポートさせる行動
   - 地面から TNT を掘り出して爆発させる行動

5. **極炎の化身（ブレイズ）**
   - 火の玉10連射
   - 爆発する火の玉
   - 地面に降りて周囲を燃やす

6. **ラグナロクイベント**
   - 発動中は全モブがエリート化

## 検証

- `mvn test`（既存163件 + 追加分）
- サーバーでビルド → テスト → 昇格 → 再起動
- 実機: 自然沸き、各固有行動、ラグナロク発動
