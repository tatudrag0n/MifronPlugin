# Mifron レリック テクスチャ アートディレクション契約 (v9)

この文書は「全部違う」「チープ」「のっぺり」を構造的に潰すための制作規約である。
**規約に沿って描けば必ずセットに見える**ように作ってある。逸脱は不可。

---

## 0. まず現状の敗因（v8 までの実測）

| 版 | 手法 | 実測された欠陥 |
|---|---|---|
| v3–v6 | PowerShell 図形 | 形が記号的、ランプなし |
| v7 | バニラ輝度保存リカラー | 画素そのまま＝色替えだけ |
| v8 | バニラ＋手描きパーツ | 土台のバニラが透けて混ざる |
| v8.5 | AI生成→16×16縮小 | 縮小で画素が潰れ、Minecraft の規律がない |
| **現行配信** | — | **33/33 が不透明黒背景 (`NO_ALPHA`)、シルエットは中央 6×6** |

現行配信の実測（`audit.py`）:
- **33/33 で透明画素が 0**。アイテムはゲーム内で**黒い四角**として描画される。
- 実際の絵は 16×16 のうち中央 6×6 程度しか使っていない。
- 残りは黒。だから「全部違う」「チープ」に見える。

→ 最優先は **透明背景** と **シルエットを画面いっぱいに**。装飾はその後。

## 1. キャンバスと占有率（絶対）

- 16×16、背景は必ず透明（`.`）。
- シルエットのバウンディングボックスは **長辺 14〜16 px**。
- 塗り面積は `kind` ごとに:
  - `weapon`（剣・槍・鎚・弓）: 10〜35%（細くて良い。ただし長辺は 15〜16）
  - `tool`（杖・竿・鎖）: 18〜45%
  - `armor`（鎧・盾・篭手）: 25〜60%
  - `object`（本・球・像・道具）: 34〜80%
- **余白は外周のみ。中央に浮かせるな**（`CENTRED_IN_BUBBLE` は失格）。

- 刃は**斜め 45°の 2〜3 px 帯**。左(上)が明、右(下)が暗。

- 白 `a` は**4 px だけ**。これが「光」を語る。

## 2. パレット（`palette.py` を使う。色を手で打たない）

各素材は `outline / dark / base / light / highlight` の5段ランプ。
色相シフト済み（影は青紫へ、光は黄へ）。**明度だけ変えたランプは禁止**。

素材: `steel rusted netherite wood bone gold copper leather`
アクセント: `lapis violet ember poison frost void shadow pale`

- 1アイテムに使う素材は **primary + accent (+ trim)** の最大3つ。
- 使ってよい文字は `render.py` の CHARMAP にある16種のみ。
- 色数（異なる文字数）は **6〜10** に収める。バニラ実測も 9〜11。
  - 少なすぎ＝のっぺり。多すぎ＝濁る。

### レアリティ既定アクセント（`accent:` 省略時の既定）
`COMMON`=bone / `UNCOMMON`=poison / `RARE`=lapis / `EPIC`=violet / `LEGENDARY`=ember

**ただし名前と見た目の一致が最優先。** 主題に合わない既定は上書きしてよい
（例: 巨人の心臓は `RARE` だが心臓は赤いので `accent: ember`）。

## 3. 光と陰（全33点で同一）

- **光源は左上に固定。** 全アイテムで同じ。ばらつくと平面に見える。
- 1つの面は **左上=明 / 右下=暗**。
- 斜め構造は **45°の階段**。歩幅を揃える（ジャギー禁止）。
- 影は**塊**で置く。散らした1px影は汚れ。
- ハイライト（`4`/`d`/`z`）は **1〜6 px**、左上寄りに**まとめる**。
  ハイライトが少ないこと自体が「光っている」を語る。
- 輪郭線（`#`/`A`/`W`）は**影側のみ**。光の当たる上・左辺では外す。
- **純黒 `#000000` 禁止。** 輪郭は必ず素材の `outline`（色味を持つ暗色）。

---

## 4. 禁止事項（レビューで即差し戻し）

- 不透明背景・半透明・グラデーション（16×16にグラデは無い）
- 枕影（縁から内側へ輪状に暗くする）
- ディザ（散らし画素）を影に使う
- 2×2 以上の単色アクセント塊（「貼った四角」に見える。点で置く）
- 孤立画素（4近傍に同色が無い画素）＝ 汚れ
- 1px 幅の「棒」だけで物体を表すこと（現行 `decayed_sword` の失敗）
- 全体が一様な単一グラデの「塊」（現行 `giantcore` の失敗）

## 5. 手順（必ずこの順で）

1. **バニラの実測を見る**（形の参考。コピーはしない）
   ```
   py vanilla_ascii.py ..\..\_review\vanilla iron_sword totem_of_undying
   ```
2. `specs/<id>.spec` を書く（ヘッダ + `---` + 16行×16文字）
3. 検証
   ```
   py render.py --spec-dir specs --check
   ```
4. 大きく描画して**目で見る**（これが最も重要）
   ```
   py render.py --spec-dir specs --out-dir ..\..\_review\v9 --quiet
   py preview.py ..\..\_review\v9 ..\..\_review\preview-v9.png --big 300
   ```
   → 画像を `read_image` で開く。**見ずに「できた」と言うな。**
5. 「名前を知らない人に1秒で伝わるか」を自問。伝わらなければ**形から作り直す**。

## 6. spec の書式

```
title: 朽ちた剣
desc: いつかの勇者の剣。全エンチャントMAXで真価を発揮する。
rarity: LEGENDARY
kind: weapon
primary: rusted
accent: ember
trim: gold
---
................
..............4.
.............324
...
(16行 × 16文字)
```

### 文字 → 色
| 文字 | 意味 | 文字 | 意味 |
|---|---|---|---|
| `.` | 透明 | | |
| `#` | primary outline | `A` | accent outline |
| `1` | primary dark | `a` | accent dark |
| `2` | primary base | `b` | accent base |
| `3` | primary light | `c` | accent light |
| `4` | primary highlight | `d` | accent highlight |
| `W` | trim outline | | |
| `w` | trim dark | `y` | trim light |
| `x` | trim base | `z` | trim highlight |

## 7. セット感の作り方（「全部違う」への回答）

セットに見えるかは **共通項の数** で決まる。以下を全点で揃える。

1. 同じ4素材ランプから選ぶ（自由色を作らない）
2. 光源が左上で固定
3. 輪郭の太さが常に 1 px、影側のみ
4. シルエットの長辺が常に 14〜16 px
5. ハイライトの量が常に 1〜6 px
6. 斜め 45° の歩幅が同じ

**差をつけるのは「形」と「アクセントの配置」だけ。** 色数を増やして差をつけない。
