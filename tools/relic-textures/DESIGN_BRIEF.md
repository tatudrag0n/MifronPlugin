## 補足

- **`enchbook` はレリックenumに存在しない孤立テクスチャ。** 予備扱い。
- `nightclock` は items/models の JSON だけがありテクスチャが無い（別件で要修正）。
- 剣・槍・鎚・弓は **45°の対角線**に置く（バニラの文法）。縦横に置かない。
- 球体・像・本・道具は**正面**に置き、画面を埋める。
- `desc` は必ず spec に写す（ツールチップと一致させるため）。
